# Topic 1: Words

What I Learned: Terms, Acronym, Recognize ambiguous pronouns.

### Terms: Use terms consistently in a single doc ( do not change terms midway in a doc ) 

### Acronym: On the initial use of an unfamiliar acronym within a document or a section, spell out the full term, and then put the acronym in parentheses. Put both the spelled-out version and the acronym in boldface. 

### Ambiguous pronouns: using pronouns properly after a noun to make the reader understand better.

### Examples
Once you've named a component Protocol Buffers, don't rename it protobufs. (terms)
This document is for engineers who are new to the Telekinetic Tactile Network (TTN) or need to understand how to order TTN replacement parts through finger motions ( acronym )
Place the pronoun as close as possible to the referring noun. In general, if more than five words separate your noun from your pronoun, consider repeating the noun instead of using the pronoun, Only use a pronoun after you've introduced the noun.
( Ambiguous pronouns )

## Topic 2: Active voice vs. passive voice

What I Learned: The vast majority of sentences in technical writing should be in active voice. In an Active voice sentence, an actor acts on a target. That is, an active voice sentence follows this formula: Active Voice Sentence = actor + verb + target. A passive voice sentence reverses the formula. That is, a passive voice sentence typically follows the following formula: Passive Voice Sentence = target + verb + actor


### Examples
Active voice example in a short sentence : The girl sat on the chair
1. Actor: the girl
2. verb: sat
3. target: the chair

Passive voice example in a short sentence : the chair was sat on by the girl
1. Target: the chair
2. was sat
3. the girl

### My Practice
rewriting passive sentence to active sentence
1. A wrapper is generated by the Op registration process.
2. Only one experiment per layer is selected by the Frombus system.
3. Quality metrics are identified by asterisks; ampersands identify bad metrics.

### My Corrections
1. Op registration process generates a wrapper
2. the Frombus system selects only one experiment per layer
3. Asterisks identify quality metrics; ampersands identify bad metrics.

## Topic 3: Clear sentences

What i learned: Many technical writers believe that the verb is the most important part of a sentence. Pick the right verb and the rest of the sentence will take care of itself. Choose Strong verb

### Examples
Weak Verb	                                            Strong Verb 
The exception occurs when dividing by zero.          	Dividing by zero raises the exception.
This error message happens when...                   	The system generates this error message when...
We are very careful to ensure...	                    We carefully ensure...

### My Practice
Clarify the following sentences by picking more specific verbs.
1. When a variable declaration doesn't have a datatype, a compiler error happens.
2. Compiler errors occur when you leave off a semicolon at the end of a statement.

### My Corrections
1. a variable declaration with no datatype generates a complier error or when a variable declaration doesn't specify a datatype, the compiler generates an error message
2. A missing semicolon at the end of a statement triggers compiler errors.

### Clear sentences ii
What i learned: Reduce There is / There are to keep sentences short and more clear for readers

### Examples
There is a variable called met_trick that stores the current accuracy.
Removing There is replaces the generic subject with a better subject. For example, either of the following sentences is clearer than the original:
1. A variable named met_trick stores the current accuracy.
2. The met_trick variable stores the current accuracy.

### My Practice
Clarify the following sentences by removing There is, and possibly rearranging, adding, modifying, or deleting other words:
1. There is a lot of overlap between X and Y.
2. There is no creator stack for the main thread
3. There is a low-level, TensorFlow, Python interface to load a saved model.
4. There is a sharding function named distribute that assigns keys.

### My Corrections
1. X and Y overlap a lot
2. the main thread does not provide a creator stack
3. TensorFlow provides a low-level Python interface to load a saved model.
4. distribute sharding function assigns keys.
